# Car Battery Seattle

Premium, conversion-driven website for **Car Battery Seattle** — a 24/7 mobile car battery delivery, installation, and testing service across the greater Seattle area.

## Tech Stack

- **Next.js 15** (App Router)
- **Tailwind CSS 4**
- **Framer Motion** (scroll animations, micro-interactions)
- **Lucide React** (icons)
- **TypeScript**

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

1. Push to GitHub
2. Import the repo at [vercel.com/new](https://vercel.com/new)
3. Deploy — Vercel auto-detects Next.js
4. Add custom domain when ready

## SEO Features

- JSON-LD LocalBusiness structured data
- Open Graph + Twitter Card meta tags
- Canonical URL
- Geo meta tags for local SEO
- robots.txt + sitemap.xml
- Semantic HTML heading hierarchy
- Alt text on all images
